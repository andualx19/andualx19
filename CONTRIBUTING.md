# Contributing to this repository

Thank you for your interest in contributing to my projects.  
This repository is primarily for academic purposes and personal learning.

## How to Contribute

1. **Reporting Issues**  
   - Use GitHub Issues to report bugs or suggest improvements.  
   - Include steps to reproduce the issue and any relevant files.

2. **Pull Requests**  
   - Fork the repository and create a new branch for your changes.  
   - Make your changes with clear commit messages.  
   - Submit a pull request with a description of your changes.

3. **Code Style**  
   - Maintain consistent formatting and indentation.  
   - Use clear and descriptive names for functions, variables, and files.  
   - Include comments where necessary to explain logic.

4. **Files and Structure**  
   - Only add files relevant to the repository structure.  
   - Do not add compiled files or IDE-specific files (use `.gitignore`).

## Note

All contributions should respect the academic and learning-focused nature of this repository.
